# 数据集保存与版本

从本次更新起，`data/` 保存导入的原始数据集，新任务的标注结果统一放在同级 `output/`。已有任务、旧草稿和历史发布包继续使用原路径，不自动搬迁，也不逆向恢复之前发生的原始数据修改。

```text
labelvla-docker/
├── data/
│   ├── aaa/                   # 原始数据集
│   └── .platform/             # 平台数据库及历史任务运行数据
└── output/
    ├── aaa/
    │   ├── .labelvla-source.json
    │   ├── aaav1/             # 第一个任务版本，完整 LeRobot 数据集
    │   └── aaav2/             # 下一任务版本，独立副本
    ├── .archives/             # 审核通过后的下载包
    └── .staging/              # 保存暂存、上一份成功保存及中断恢复
```

## 流程

1. 新建任务，选择原始数据集、起始版本、标注负责人及审核负责人，点击发布。
2. 发布任务时立即复制完整数据集到 `output/aaa/aaavN`，并在版本管理登记为「标注中」。编号同时避让历史版本和已有目录，不覆盖已有数据。
3. 工作区打开该 output 版本。标注、目标框、轨迹和 SAM 轮廓保存在这个版本的 `segments/`。
4. 点击「保存修改」，裁剪、删除片段和标注都保存回同一个 `aaavN` 目录。保存时先在 output 暂存并校验，成功后替换目录，失败不切换当前版本。仅修改标注时不重新编码视频。
5. 完成标注、审核和程序质检后，将同一版本标记为「已发布」并生成下载包，不再另建一个新版本目录。已发布版本不可直接编辑。
6. 下一轮修改新建任务，可选择原始数据或某个已经发布的版本作为起点，生成 `aaav(N+1)`。旧版保留。

界面中的 `V1.0` 对应目录 `aaav1`。已有历史版本会参与编号，因此首次使用新结构不一定从 v1 开始。创建失败或取消的目录不自动删除；它们的编号不会复用。

每个 output 版本包含完整视频、Parquet、meta 和标注，不使用硬链接共享原始文件。原始数据挂载为只读，平台数据库目录单独读写。嵌入式图像和深度特征的裁剪导出仍按原有支持范围处理。

## Docker 与备份

宿主机 `data/` 对应容器 `/data`，`output/` 对应 `/output`。启动时配置 `LABELVLA_DATA_ROOTS=/data:/output`，并挂载 `output:/output`。完整配置见部署文档。

备份须同时保留代码、`data/` 和 `output/`；`.platform/platform.db` 保存任务及版本引用。`.staging/` 每个任务最多保留一份上次成功保存的完整副本及必要的恢复文件，未完成上传暂存不自动清理。
